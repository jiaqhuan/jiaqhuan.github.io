# jiaqhuan.github.io

这是一个 GitHub Pages 静态网站仓库，当前主要文件：

- `index.html`：网站主页（弹性闹钟）
- `README.md`：项目说明

## 如何用手机端远程继续编程

### 1) 轻量改动：GitHub 网页端直接改

适合：改几行文案、修小问题。

步骤：

1. 手机浏览器打开仓库页面。
2. 进入要修改的文件（如 `index.html`）。
3. 点击编辑按钮（铅笔图标）。
4. 修改后填写 commit message 并提交。

### 2) 接近本地开发：`github.dev`

适合：多文件编辑、全局搜索、快速提交。

步骤：

1. 在手机浏览器打开仓库页面。
2. 把地址栏里的 `github.com` 改成 `github.dev`。
3. 进入网页版 VS Code 后编辑、提交即可。

### 3) 完整开发环境：GitHub Codespaces（推荐）

适合：需要终端、运行命令、持续开发。

步骤：

1. 仓库页面点击 **Code**。
2. 选择 **Codespaces**。
3. 点击 **Create codespace on main**（或默认分支）。
4. 在手机浏览器中的云端 VS Code 继续开发并提交。

## 发布流程（本仓库）

1. 修改并提交 `index.html`。
2. push 到默认分支后，GitHub Pages 会自动重新部署。
3. 等待几分钟后访问站点确认更新。

## 手机端建议

- iOS：优先用 Safari 打开 GitHub / github.dev / Codespaces。
- Android：优先用 Chrome 打开以上页面。
- 网络不稳定时，优先使用 GitHub 网页端直接改文件，最省流量也最稳。
